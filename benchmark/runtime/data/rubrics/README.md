# Central Rubric Rules

Canonical rubric copies for reproducible runs are stored here.

## Version mapping
- `rubric_rules_v3.json`
  - Source: `benchmark/runtime/data/verification/v4/rubric_rules_v1.json`
  - Notes: v3-era legacy rule set.
- `rubric_rules_v4.json`
  - Source: `benchmark/runtime/data/verification/v4/rubric_rules_v2.json`
  - Notes: v4 review rubric.
- `rubric_rules_v4_1.json`
  - Source: `benchmark/runtime/data/verification/v4/rubric_rules_v2.json`
  - Notes: v4.1 uses the same rubric content as v4 (`rule_version: v2`).

## Usage
When running review scripts, reference files in this directory for stable rule pathing.
