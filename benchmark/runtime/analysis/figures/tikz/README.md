# TikZ Figures

One folder per figure/output group.

| Folder | Figure title / purpose |
|---|---|
| `combined` | Combined multi-panel TikZ compilation |
| `fig1_categories` | DSM-5 category distribution |
| `fig2_conditions` | Top conditions distribution |
| `fig3_severity` | Severity distribution |
| `fig4_modalities` | Therapeutic modality distribution |
| `fig5_per_study` | Per-study category breakdown |

Each folder contains source `.tex`, compile wrapper `_compile_*.tex`, and generated artefacts (`.pdf`, `.log`, `.aux`).
