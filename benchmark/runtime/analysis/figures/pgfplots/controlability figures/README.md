# PGFPlots Figures

Each figure lives in its own folder named from the figure title. The top level is grouped by bundle size so the layout stays tidy:

- `main/` for the standard controllability figure set.
- `small_scale/` for the reduced small-scale bundle.
- `scaled/` for the scaled large-resolved bundle.
