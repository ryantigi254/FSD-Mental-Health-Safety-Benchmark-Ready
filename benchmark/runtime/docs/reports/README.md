# Reports Index

This folder is organised into stable subfolders:

- `clinician_package/`
  - Versioned clinician send-off artefacts (`v0.2`, `v0.3`).
  - Includes review CSVs, manifests, and gate/preflight reports.

- `comparisons/`
  - Cross-run and cleaning comparison markdown reports.

- `audits/`
  - One-off audit artefacts and validation exports (CSV/JSON).

Notes:
- Stage-2 and preflight automation continue to write under `clinician_package/v0.3/`.
- Study B standalone construct validation defaults to `audits/study_b_construct_validation.csv`.
